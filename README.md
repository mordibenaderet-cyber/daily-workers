# יומן פועלים — v10 SIMPLE + PDF

אפליקציית Web חינמית, בעברית, במבנה טבלה עם ארבע עמודות בלבד: **פועל ותמונה | תאריך | כניסה | יציאה**.

## מה חדש בגרסה זו

- **אין צורך במיקום עבודה**: אין שדות מיקום או מלאכה במסך העבודה או בדוחות. נתונים היסטוריים נשמרים ברקע לתאימות עם גיבויים ישנים.
- **קיבוץ לפי חברת כוח אדם**: כל הפועלים מאותה חברה מופיעים ברצף, עם שורת כותרת של שם החברה. הקיבוץ קיים גם ב-PDF.
- **חברת כוח אדם בכרטיס הפועל**: בעת הוספה או עריכה של פועל יש לבחור/להקליד את שם החברה. הנתון הזה היה שמור כבר בחלק מהגרסאות הישנות, ולכן לא נעלם בעדכון.
- **דוח PDF אמיתי**: לחצן ״דוח PDF״ מעל הטבלה, בחירת מתאריך/עד תאריך, הורדה ישירה של PDF בגודל A4 הכולל ארבעה טורים בלבד: פועל ותמונה, תאריך, כניסה, יציאה.
- **ייצוא ללא חיבור אינטרנט**: ה-PDF נוצר בדפדפן כולל התמונות, ללא ספריות CDN וללא העלאת המידע לשרת. נדרש מכשיר שתומך ב-Canvas וב-Blob (דפדפנים מודרניים).
- שדות כניסה ויציאה מקבלים `07:30`, `730`, או `7:30`, וטעינת הנתונים נשארת דרך IndexedDB.

## דיווח והפקת PDF

1. בוחרים תאריך ומזינים שעות כניסה ויציאה ליד כל פועל.
2. לוחצים **שמור שינויים** — כדי להכניס את השעות לדוח.
3. לוחצים **דוח PDF**.
4. בוחרים את תחילת וסוף התקופה. ברירת המחדל היא התאריך הנוכחי שבטבלה.
5. לוחצים **הורד PDF**. הדוח כולל רק ימי עבודה שנשמרו בתקופה. בשורות ששעותיהן לא נרשמו, יוצג מקף ולא שעה מומצאת.

ה-PDF הוא דוח חזותי מבוסס תמונה, כדי לשמור על עברית והתמונות גם באייפון; הוא מתאים לצפייה, שיתוף והדפסה אך אינו נועד להעתקה או חיפוש טקסט בתוך PDF.

## עדכון הקיים דרך GitHub Pages

1. לפני העדכון מורידים גיבוי מהגרסה המותקנת (בתפריט ⋯).
2. מחלצים את ה-ZIP ומעלים את **כל הקבצים והתיקיות שבתוכו** לשורש המאגר הקיים (`index.html`, `app.js`, `pdf-export.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icons/`).
3. מחכים לסיום הפריסה ומוודאים שבאפליקציה מופיע **גרסה 10 · SIMPLE**.
4. לא מוחקים את נתוני האתר ולא משנים את כתובת GitHub Pages; הנתונים נשמרים מקומית בדפדפן.

## תאימות, פרטיות וגיבוי

- הנתונים נשמרים ב-IndexedDB תחת `mordi-daily-workers`, כמו בגרסאות קודמות.
- זיהוי החברה מסתמך על `worker.company`. עובדים שהחברה שלהם לא הייתה ידועה יוצגו בקבוצת "לא צוין"; אפשר לעדכן אותה ב״ניהול פועלים״.
- תמונות שמורות באותו מכשיר ונכנסות ל-PDF כאשר הוזנו.
- במקרה של דפדפנים שונים או כתובת אתר שונה, יש להעביר מידע באמצעות **גיבוי ושחזור**.
- אין סנכרון אוטומטי בין מכשירים ואין שרת.
