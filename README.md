# ניהול יומיות – אפליקציה לניהול פועלים

אפליקציית Web חינמית בעברית, המותאמת למחשבים ולטלפונים ניידים.

## מה אפשר לעשות?

- ליצור לכל פועל כרטיס עם תמונה, שם וחברת כוח אדם.
- לשבץ פועל בכל תאריך, ולהוסיף לאותו פועל מספר מיקומי עבודה ומספר מלאכות באותו יום (טקסט חופשי).
- להזין בבוקר שיבוץ ראשוני ובסוף היום לערוך את היום ולהוסיף שורות של מיקום ומלאכה בפועל. מנהל העבודה לא חובה.
- לראות את כל השיבוצים לפי תאריך, חברה או חיפוש חופשי.
- להציג היסטוריית שיבוצים של כל פועל ולנווט לתאריך מסוים.
- להעתיק מיקומים מהיום הקודם, בלי להעתיק מלאכות שבוצעו ובלי לדרוס שיבוצים קיימים.
- להפיק דוח תקופתי עם סיכום **ימי פועל ללא ספירה כפולה**, ופירוט כל מיקום ומלאכה בשורה נפרדת.
- להוריד דוח CSV בעברית שנפתח באקסל (כולל BOM), ולהדפיס דוח כ-PDF.
- להוריד גיבוי JSON מלא (כולל תמונות), ולשחזר אותו.
- להגדיר פועלים כלא פעילים, בלי לאבד את היסטוריית העבודה שלהם.

## העלאה לאינטרנט בחינם

### Netlify
1. חלצו את קובץ ה-ZIP לתיקייה.
2. גררו את התיקייה המכילה את `index.html` (לא תיקיית-האב) לעמוד הפריסה של Netlify, או העלו את קבצי התיקייה באמצעות הממשק.
3. פתחו את כתובת האתר שתקבלו.

### GitHub Pages
1. צרו מאגר חדש ב-GitHub.
2. העלו **את כל הקבצים שבתיקייה**, כולל תיקיית `icons`, לראש המאגר (לא את קובץ ה-ZIP עצמו).
3. בהגדרות המאגר בחרו `Pages` → `Deploy from a branch` → `main / (root)`.
4. לאחר פרסום האתר, פתחו את הקישור בלשונית Pages.

### התקנה באייפון
פתחו את כתובת האתר ב-Safari → כפתור שיתוף → **הוסף למסך הבית**.

## נתונים וגיבוי

- האפליקציה אינה דורשת שרת או הרשמה. היא שומרת את הנתונים ב-IndexedDB של הדפדפן המקומי. נתוני גיבוי נשמרים בקובץ JSON בידי המשתמש.
- אין סנכרון אוטומטי בין מכשירים או משתמשים שונים. העלאת אותה אפליקציה לדומיין אחר יוצרת מאגר חדש ונפרד; יש לייצא ואז לשחזר גיבוי כדי להעביר נתונים.
- מחיקת נתוני האתר בדפדפן, גלישה פרטית או אובדן המכשיר עלולים לגרום לאובדן נתונים. מומלץ גיבוי JSON תקופתי.
- תמונות מוקטנות אוטומטית לצורך שמירה יעילה.
- השיבוצים מייצגים **תיעוד של הקצאות עבודה**; הם אינם מערכת נוכחות מאומתת או חישוב שכר.
- כדי להשתמש ללא חיבור לאינטרנט, יש לפתוח את האתר פעם אחת כשהמכשיר מחובר. תמיכת Offline תלויה בדפדפן ובהגדרות שלו.

## תכולת הקבצים

- `index.html` – מסכי האפליקציה
- `styles.css` – עיצוב ותגובה לגדלי מסך
- `app.js` – לוגיקת שיבוצים, דוחות ונתונים
- `manifest.webmanifest` – פרטי התקנה כסימנייה/אפליקציית PWA
- `sw.js` – שמירת קובצי האפליקציה לשימוש לא מקוון
- `icons/` – לוגו ואייקונים
