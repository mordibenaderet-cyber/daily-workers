# ניהול יומיות | גרסה 7 PRO

אפליקציית Web בעברית לניהול פועלים ביומית, מותאמת לאייפון, אנדרואיד ומחשב. האפליקציה חינמית ופועלת ללא שרת.

## מסכי האפליקציה

1. **יומן עבודה:** בוחרים תאריך; משבצים כל פועל פעם אחת ביום; מוסיפים כמה מיקומי עבודה וכמה מלאכות שביצע; מזינים מנהל עבודה אם צריך. אפשר להעתיק מיקומים מאתמול בלי להעתיק שעות או מלאכות.
2. **דיווח שעות:** מזינים שעת כניסה ושעת יציאה פעם אחת לכל פועל ביום. משך העבודה מחושב ונשמר אוטומטית לאחר לחיצה על ״שמור שעות״. אפשר להקליד `07:30` או `0730`. שעה שמוקדמת משעת הכניסה מחושבת כיציאה ביום הבא. אין ניכוי הפסקות אוטומטי.
3. **פועלים:** תמונה, שם, חברת כוח אדם, סטטוס פעיל/לא פעיל, עריכה והיסטוריית ימים.
4. **דוחות וגיבוי:** סיכום לפי פועל ולפי חברה; פירוט יומי של כניסה, יציאה וסך שעות; פירוט כל המיקומים והמלאכות; ייצוא CSV שמתאים לאקסל; הדפסה/שמירה כ-PDF; גיבוי ושחזור JSON מלא (כולל תמונות).

## שדרוג של אתר קיים ב-GitHub Pages

1. **לפני כל שינוי:** באפליקציה הנוכחית פתחו ״דוחות וגיבוי״ והורידו **גיבוי מלא**. שמרו את קובץ ה-JSON במקום בטוח.
2. חלצו את קובץ `daily-workers-app-v7-pro.zip`.
3. היכנסו ב-GitHub למאגר הקיים, ובענף `main` העלו **את תוכן התיקייה** (לא את ZIP): `index.html`,‏ `app.js`,‏ `styles.css`,‏ `sw.js`,‏ `manifest.webmanifest`,‏ `README.md` ותיקיית `icons`. אם נשאלתם, אשרו החלפת הקבצים הקיימים.
4. לחצו `Commit changes`. המתינו לפרסום ב-GitHub Pages, ואז פתחו **באותה כתובת אתר** שהייתה קודם.
5. ודאו שבכותרת מוצג **v7 PRO**. אם עדיין מופיעה גרסה קודמת, פתחו את האתר בחלון Safari חדש ובצעו רענון; אין למחוק נתוני אתר לפני שיש לכם גיבוי.

הכתובת באתר GitHub: `Repository → Settings → Pages → Visit site`. אם פרסמתם ב-Netlify, העלו את אותם קבצים לפרויקט הקיים.

## שמירת מידע ותאימות

- הנתונים נשמרים ב-**IndexedDB** של הדפדפן. שם המאגר ושמות הטבלאות זהים לגרסאות 1–6, כך שעדכון באותה כתובת ובאותו דפדפן אמור לשמר את כל הנתונים.
- קובצי גיבוי קודמים נתמכים: רשומות ישנות עם **סך שעות בלבד** יישארו כך. לא יומצאו עבורן שעות כניסה ויציאה.
- פועל שעבד בכמה מיקומים ביום נספר כיום עבודה אחד, והשעות נספרות פעם אחת בלבד.
- אין סנכרון בין מכשירים או משתמשים. דפדפן חדש, מכשיר חדש, שינוי דומיין או מחיקת נתוני האתר מחייבים שחזור מהגיבוי.
- זהו יומן ניהול ולא מערכת נוכחות מאומתת או מנגנון חישוב שכר.

## פירוט קבצים

- `index.html` — מסכים, טפסים וניווט.
- `styles.css` — עיצוב מובייל ודסקטופ.
- `app.js` — ניהול מאגר, חישובי שעות, דוחות, גיבויים.
- `sw.js` — עבודה במטמון ועדכון קובצי האתר.
- `manifest.webmanifest` — פרטי התקנה כאפליקציה.
- `icons/` — אייקונים להתקנה במסך הבית.
