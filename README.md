# יומן פועלים – גרסה 9 SIMPLE

אפליקציית Web בעברית למסך אחד: פועל ותמונה | תאריך | כניסה | יציאה.

- בחירת תאריך למעלה מציגה את כל הפועלים הפעילים, עם זמני כניסה/יציאה לאותו יום.
- הוספת פועל ותמונה דרך "הוסף פועל". לחיצה על שם פועל פותחת עריכה.
- אפשר להזין שעות `07:30`, `730`, או `7:30`; יש ללחוץ על **שמור שינויים**.
- סך השעות מחושב אוטומטית, כולל משמרות המסתיימות ביום הבא. אין ניכוי הפסקות.
- בתפריט ⋯ יש ייצוא CSV, הורדת גיבוי JSON, שחזור גיבוי, וניהול פועלים.
- הנתונים נשמרים במכשיר/דפדפן באמצעות IndexedDB, ללא שרת או סנכרון.
- התוכנה משתמשת באותו מסד נתונים (`mordi-daily-workers`) של הגרסאות הקודמות ומשמרת גם פרטים שאינם מוצגים כאן (חברת כוח אדם, מיקומים ומלאכות). יש לבצע גיבוי לפני העדכון.
- שיבוצים היסטוריים ששמרו רק סך שעות אך לא שעת כניסה ויציאה נשמרים, והזמנים לא מומצאים.

## העלאה ל-GitHub Pages

1. הורד גיבוי מהאפליקציה הישנה (⋯ / גיבוי).
2. חלץ את קובץ ה-ZIP החדש.
3. העלה את **תוכן** תיקיית `daily-workers-simple` (ולא התיקייה עצמה) לשורש המאגר הקיים: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, ותיקיית `icons`.
4. המתן לסיום פריסת GitHub Pages ופתח שוב את אותה הכתובת. וודא שכתוב בראש: **גרסה 9 · SIMPLE**.
5. אל תמחק נתוני גלישה ואל תשנה כתובת/דפדפן, אחרת הנתונים המקומיים לא יימצאו. אפשר לשחזר מגיבוי אם צריך.

## פרטיות וגבולות

שמות ותמונות נשמרים רק בדפדפן. ייצוא CSV כולל רשומות לכל התאריכים, ויכלול סך שעות כעמודה חמישית בדוח בלבד, ולא בטבלת האפליקציה.
